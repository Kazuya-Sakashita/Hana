## 7. ホットスポット要約 (調査結果から)

CLI 実測 + コード調査 (ISSUE-016 着手時) で見えている明らかな改善余地:

1. **`/album` の N+1**: 50 件のメモごとに `/uploads/{id}/url` を並列発行 → ISSUE-018 で BFF 化
2. **画像が原寸**: `<img>` 直接で 80×80 表示なのに 1〜3 MB 送信 → ISSUE-019 / 028
3. **`requireUser()` の profile.upsert** が全ルートで毎回実行 → ISSUE-017
4. **`/me` `/children` の 4 ページ重複 fetch** → ISSUE-023 (Tanstack Query)
5. **Client Component first**: 全 7 ページが `'use client'` → ISSUE-025〜027 で Server Component 化
6. **`loading.tsx` 未使用** → ISSUE-020
7. **AI generate の Storage DL + sharp が直列** → ISSUE-022
